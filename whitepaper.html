01

概述

Overview

Agent Ascent（ASC）是部署在 BNB Smart Chain 上的阶梯价公平发射代币（V7），由 FairMint Arena（FMA2）经 V6 relaunch 而来。代币与铸造合约同一地址，规则全部写死，无 owner、无暂停、无预挖、无团队代币。铸造需持 .ai Agent ID（门禁）；V6 全部 149 份已1:1 等值迁移完成，无需任何操作。

生命周期以「份数（shares）」推进：总量 4,440,000 份，每份 500,000 ASC（85% 到手 425,000，15% 进预留）；价格按份数阶梯每 10,000 份 +0.1U（1.2U 起、8U 封顶）；累计满 10,000 份任何人可调用 launch() 开池；开池后仍可以 BNB 继续铸造直至售罄。V6 全部 149 份已 1:1 迁入 V7，其后为 Agent-ID 门禁下的新铸造（实时份数见主页 / BscScan）；未开池，下一份 1.2U。

阅读约定：下文 code 为合约函数 / 常量原名；数值常量以已验证源码与链上读数为准。主页面向用户的说明不含这些术语，本页是它们的唯一出处。

铸造机制

Minting

V7 铸造需持 .ai Agent ID：mint(uint8 shares, bool useUsdt) 首行校验 registry.handleOf(msg.sender) 非空（否则 revert NEED_AGENT_ID），迁移 migrate() 不受此限。shares 为本次总份数（含免费首份），1–10；每钱包付费份累计不超过 10 份；前 1,000 个钱包各享 1 份免费（freeUsed 标记，退款后返还名额）。

// AgentAscentV7.sol · 门禁 + 报价与支付校验（简化）
require(bytes(IAgentRegistry(registry).handleOf(msg.sender)).length > 0, "NEED_AGENT_ID");
function quote(address who, uint8 shares) public view returns (uint256 usdCost);
// 免费首份计 0；其余逐份按 priceUsdAt(totalShares + i) 累加
uint256 bnbCost = bnbForUsd(usdCost);  // 1U = 0.00146667 BNB（固定换算）
require(msg.value == bnbCost, "BAD_VALUE");
  • 币种：USDT 仅开池前可用（需先 approve，按美元成本精确划转）；BNB 全程可用，msg.value 必须等于换算值，多一分都不收。
  • 免费份：也占份数 idx 与总供应；免费 + 付费合并一次 mint，免费名额用完后全部按阶梯价。
  • 开池后：仅 BNB（USDT_PRE_ONLY）；每笔含 10% 团队费（30% 回购烧毁 / 70% 团队）；开池后新铸份额不锁仓，立即可转（卖出税照常）。
  • 售罄：totalShares 达 4,440,000 后 mint 永久 revert（SOLD_OUT），此后只能二级市场交易。

等值迁移（已完成）

Migration

V6 的 149 份已全部 1:1 迁移到 V7（其中含更早从 FMA2 迁入 V6 的 9 份）。迁移由 migrate(address who) 完成：permissionless crank，任何人可代为触发，只读 V6（legacy）公开记录，按 1:1 份数计入 V7，每个地址仅一次，开池后关闭；迁移不校验 Agent-ID（门禁仅针对新铸造）。

// AgentAscentV7.sol · 迁移曲柄（简化，legacy = V6）
function migrate(address who) external {
    require(!launched, "LAUNCHED");
    require(!refunded[who], "REFUNDED");
    uint256 old = ILegacy(legacy).mintedShares(who);
    require(old > 0, "NOTHING");
    require(mintedShares[who] == 0, "DONE");
    // 1:1 记份数，同步 paidShares / freeUsed；按 old × 500,000 铸币（85% 到手 / 15% 预留）
}
保障实现
1:1 等值读 V6（legacy）mintedShares 记同样份数；代币按新口径每份 500,000（85% 到手）
一次性要求新合约 mintedShares[who] == 0，重复调用 revert（DONE）
无需授权只读旧合约公开 getter，不触碰用户私钥 / approve / 签名
退款排除新合约已退款地址（refunded）不可再迁移
总量约束迁移份数计入 totalShares，不超 MAX_SHARES；仅开池前可调用
用户视角：无需任何操作，已完成。迁移份额与新铸份额完全同权（含开池前锁仓口径）；主页权益查询可直接读到新合约份数。

防狙击与解锁

Anti-snipe & Unlock
机制规则
卖出税开池后 2 小时内从 80% 阶梯降到 0：<10min 80% · <20min 50% · <30min 30% · <50min 20% · <80min 10% · <120min 5% · 之后 0%（currentSellTaxBps）；税的 70% 分红、30% 销毁
早鸟解锁开池前所得（p1Allocation，含迁移）全部锁定至开池；开池后每天剩余锁定 × 39%（第 1 天最多卖 61%），第 7 天全部解锁；开池后新铸份额不锁
退款窗口本钱包首铸满 24h 后可退款（BNB 与 USDT 实付均退）；开池后关闭，给铸造者冷静期
解锁公式：daysElapsed = (now − launchTime) / 1天 + 1；remaining = alloc × 0.39^daysElapsed，≥ 7 天归零。可转数量 = balanceOf − lockedOf（unlockedOf 直接可读）。
